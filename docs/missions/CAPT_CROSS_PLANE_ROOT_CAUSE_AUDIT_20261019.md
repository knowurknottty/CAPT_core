Known provider diagnostics during the window include OpenRouter HTTP 404 (Oct 8 and Oct 18), 402 (Oct 10–11), 400 (Oct 12 and Oct 17), and a response-body timeout (Oct 13). Oct 18 also included a response_completed/lost case. A provider's HTTP status alone is not proof of CAPT or provider fault. Reported `providerHttpRequestAttempts` is a count of physical HTTP attempts within a run, including tool rounds and any configured retries; **it must not be represented as a pure retry count without individual dispatch receipts**.

## Reliability policy required for the next release

1. Treat each model call as a **state machine with explicit `not_dispatched`, `request_started`, `response_completed`, `artifact_persisted`, `settlement_unknown`** stages. A completed HTTP response without persisted output must retain durable sanitized diagnostic and candidate bytes where permitted, not be coerced into a completed claim.
2. `PROVIDER_NO_CONTENT`, `PROVIDER_MODEL_UNAVAILABLE`, `PROVIDER_ACCOUNT_UNAVAILABLE`, `PROVIDER_MODEL_PREFLIGHT_UNAVAILABLE`, `PROVIDER_HTTP_ERROR`, transport timeouts, and `HUMAN_APPROVAL_REQUIRED` must remain distinct. In particular, governance denials are not runtime faults to bypass.
3. Provider preflight must be scoped to the authorized exact model and provider, never dynamically choose a cheaper/different model behind the approval. Return a clear result and allow the operator to make a fresh model choice.
4. Separate tool-round count, physical POST attempts, and automatic retries in all diagnostics. For HTTP 400, retain sanitized accepted parameter set and provider error code only (no private prompt or key).
5. Add daily reliability dashboard: scheduled tasks, ready vs stale capabilities, per-provider failure rate, cost of lost/charged runs, reconciliation queue, and bridge process/readiness. Audit log retention and privacy policy must be specified.
6. Move watchdog and installed CLI onto a coherent released wheel/reproducible deployment, and add signed version/source-digest attestation for RuntimeService, CLI, Node, MCP, Bot and TIA. Report drift rather than continuing silently on older code.
7. Run a zero-cost, fault-injected certification covering socket shutdown/reconnect, SIGTERM, reader timeout, HTTP 400/402/404, malformed response parts, outcome unknown after POST, oversized model context permission, and two independent authenticated operators.
