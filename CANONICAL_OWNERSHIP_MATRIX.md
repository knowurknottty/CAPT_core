# CANONICAL OWNERSHIP MATRIX — Workspace Entrypoint

This root file is the discoverable entrypoint required by the CAPT Universal
Workspace contract. It is **not** a duplicate of the ownership matrix.

The full ownership matrix — component, canonical home, current repo/path, planned
public repo, current status, canonical maturity, maturity evidence, and owner
decision gates — lives at:

    docs/CANONICAL_OWNERSHIP_MATRIX.md

The machine-readable companion is `architecture/registry.yaml`. Architectural
debt is tracked in `architecture/debt.yaml` and `docs/ARCHITECTURAL_DEBT.md`.
